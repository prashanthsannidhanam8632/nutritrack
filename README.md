# 🥗 NutriTrack — Python Edition

AI-powered nutrition tracker built with Python and Streamlit.

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```

Opens at: http://localhost:8501

## Features
- 🏠 **Home** — Log meals, track macros, set daily goals
- 📖 **Recipes** — 150+ recipes across 10 cuisines
- 🍳 **Cook** — Step-by-step cooking guide with ingredient macros
- 📊 **Summary** — Charts and daily nutrition breakdown

## Deploy Free
[![Deploy on Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)

1. Push this repo to GitHub
2. Go to share.streamlit.io
3. Connect your repo → Deploy
